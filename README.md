# AgroMarket – Módulo Catálogo de Productos

## Descripción
Este repositorio contiene el módulo de **Catálogo de productos** para AgroMarket.

El módulo permite:
- Ver un listado de productos agrícolas.
- Filtrar productos por categoría (frutas, hortalizas, granos, tubérculos).
- Consultar el detalle de cada producto.
